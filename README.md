# 仙途·人生重启

> 一个修仙题材的人生模拟器游戏。选择你的天赋，踏上修仙之路，体验从炼气到元婴的完整仙途！

## 🎮 游戏介绍

《仙途·人生重启》是一款以修仙文化为背景的人生模拟游戏。在游戏中，你将扮演一位修仙者，从炼气期开始，通过选择天赋、经历各类事件、修炼功法、获取丹药，一步步冲击更高的境界，最终证道元婴！

## ✨ 核心玩法

### 境界系统

游戏包含五大修仙境界：

- **炼气期** → 筑基期 → 金丹期 → 元婴期 → 渡劫期

每个境界都有丰富的事件内容和独特的挑战。

### 天赋抽卡

开局可抽取随机天赋，天赋分为四种品级：

| 品级 | 颜色 | 说明 |
|------|------|------|
| 普通 | ⚪ 白色 | 基础属性加成 |
| 优秀 | 🟢 绿色 | 明显的属性增益 |
| 稀有 | 🟠 橙色 | 强力的特殊效果 |
| 厄运 | ⚫ 黑色 | 负面天赋，挑战加倍 |

可选择「十连抽」或「单次抽取」，每次游戏可重抽天赋。

### 事件系统

游戏中有 **655+ 个精心设计的事件**，涵盖：

- 🏯 **宗门管理**：拜师学艺、宗门任务、同门关系
- ⚔️ **战斗历练**：野外遇敌、副本攻略、心魔挑战
- 💊 **丹药获取**：炼丹任务、拍卖购买、BOSS 掉落
- 📜 **功法奇遇**：悟道机缘、洞府传承、前辈指点
- 💰 **经济系统**：坊市交易、灵石管理、财富积累
- 💕 **社交关系**：道侣结缘、子嗣传承、恩怨情仇
- ⚠️ **背德事件**：阴谋算计、坑害同门、黑吃黑

### 丹药获取

突破丹药可通过多种途径获取：

- 筑基丹：奇遇机缘、助人积德、副本BOSS掉落（10-30%）、坊市购买（500灵石）、炼丹师任务
- 结丹丹：副本BOSS掉落（30%）、炼制、任务奖励
- 元婴丹：副本BOSS掉落（20-30%）、拍卖会、炼制

### 副本战斗

人形BOSS会概率掉落当前境界的突破丹药，掉落概率随敌人强度提升：

- 普通敌人：10-15%
- 精英敌人：20%
- 头目级敌人：25-30%

## 🎨 界面主题

游戏提供两种界面主题：

- **默认主题**：清新简洁，适合长时间游玩
- **赛博主题**：霓虹风格，体验未来修仙感

支持字体大小调整，适应不同阅读需求。

## 🚀 快速开始

### 作为玩家

> 即将上线！请关注后续发布信息。

### 作为开发者

#### 环境要求

- Node.js >= 18
- pnpm >= 8

#### 安装与运行

```bash
# 1. 克隆项目
git clone <repository-url>
cd xiantu-life-restart

# 2. 安装依赖
pnpm install

# 3. 启动开发服务器
pnpm dev
```

访问浏览器打开 `http://localhost:5173` 即可游玩。

#### 常用命令

```bash
# 开发模式
pnpm dev

# 构建生产版本
pnpm build

# 预览生产版本
pnpm start
```
